# Architecture Decision Records (ADR)

Use ADRs to capture durable platform decisions.

## Process

1. Create a file in `docs/adr/` named `NNNN-short-title.md`.
2. Keep decision status updated (`proposed`, `accepted`, `superseded`).
3. Link related issues/PRs and affected components.
4. When superseding, add forward/back references.

## Template

```md
# ADR NNNN: Title

- Status: proposed
- Date: YYYY-MM-DD
- Decision makers: @team

## Context

## Decision

## Consequences

## Alternatives considered
```
